
# Unity Competitor AI

Командный учебный проект, разработанный на игровом движке Unity с использованием языка C#. В рамках проекта реализована система искусственного интеллекта компьютерного соперника, способного адаптировать своё поведение в зависимости от состояния игрока.

## Технологии

- C# — разработка игровой логики и алгоритмов ИИ
- Unity — игровой движок
- Git — контроль версий
- GitHub — совместная разработка

## Мой вклад в проект

Моя зона ответственности — разработка логики искусственного интеллекта компьютерного соперника.

- Разработка алгоритмов адаптивного поведения ИИ.
- Реализация принятия решений на основе состояния игрока.
- Обработка игровых событий и изменение поведения соперника.
- Интеграция логики ИИ с игровыми механиками.
- Использование Git и GitHub для командной разработки.

**Основной файл моей разработки:** `Assets/Scripts/AI/CompetitorAI.cs`.

## Структура проекта

- `Assets/` — игровые ресурсы, сцены и скрипты C#.
- `Packages/` — зависимости Unity.
- `ProjectSettings/` — настройки проекта.

## Запуск проекта

1. Клонировать репозиторий.
2. Открыть проект через Unity Hub.
3. Использовать версию Unity, указанную в `ProjectSettings/ProjectVersion.txt`.
4. Открыть игровую сцену и запустить проект в Unity Editor.
